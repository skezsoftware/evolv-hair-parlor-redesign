# Êvolv Hair Parlor

Modern redesign for [Êvolv Hair Parlor](https://www.evolvhairparlor.com/) — a hybrid salon in Hillcrest, San Diego.

Built with React, Vite, and React Router. All salon content lives in `src/data/salon.js`.

## Pages

- Home
- Services
- Team
- Our Story
- Contact

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Images are Unsplash placeholders for now. Drop real photos into `public/images/` and update paths in `src/data/salon.js`.
